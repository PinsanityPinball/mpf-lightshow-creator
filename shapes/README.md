# Shape images

These 31 PNGs are **not** covered by this project's MIT licence.

They are the shape bitmaps from the original BlitzMax show creator —
<https://github.com/missionpinball/showcreator> — by **Mark Incitti**, and are
included here with his permission. That repository carries no licence of its
own, so the images remain his; permission to use them here does not extend to
relicensing them or redistributing them separately.

If you fork this project and intend to redistribute it, either ask Mark as well
or drop this folder. Dropping it is cheap: the 18 built-in shapes are drawn
procedurally in `web/js/shapes.js` and do not touch these files. Only the
separate "image shape" path reads them, via `/api/shapes`.
